# grape-leaf-disease-classification
This project focuses on grape disease classification using deep learning and image processing. The model is trained to identify different grape disease categories from images.

The project includes data preprocessing, model training, validation, and performance evaluation. All experiments and results are provided in the grape.ipynb Jupyter Notebook.
